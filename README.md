# 三体世界图鉴

面向没读过《三体》的人：顺着时间线，读懂整个三体故事；也为读过的人提供概念与人物都能查的全景图鉴。全站剧透，以刘慈欣《三体》三部曲为唯一正史。

## 功能一览

- **时间线**：五纪元年表长卷，大事件附「关键转折」解读块与沉浸场景入口
- **全景图谱**（`/graph`）：交互式知识图谱——三卷脉络、人物交会、概念相连。节点/边从内容数据自动派生，骨架层（~37 节点）/ 全量层（113 节点）切换，类型筛选，悬停锁定高亮 + 悬浮详情卡（点击直达详情页），拖拽/滚动平移缩放
- **概念册 / 人物墙**：每条设定「书里怎么讲 + 科学底子」，人物四段式来路 + 「他的遗产」
- **大场面沉浸页**：水滴末日战役等场景（Canvas 特效 + 六段叙事）
- 解读层字段（关键转折 / 细思极恐 / 遗产）逐实体补全中

## 构建技术

- **Astro 5** 纯静态生成；客户端仅渐进增强（星空/场景 Canvas、图谱交互、滚动渐显），零框架零运行时依赖
- 深空视觉体系：近黑底色 + 暗角星云渐变 + 胶片噪点层，苍黄（红岸）× 冷蓝（宇宙）双强调色
- `content/` 六套 JSON 数据源（书 / 纪元 / 事件 / 概念 / 人物 / 场景）以 id 互相引用、双向对称校验
- 知识图谱数据管线：`buildGraph` 派生节点/边（跨类型同名 id 命名空间隔离）+ 确定性分层坐标布局（纯函数，可测）
- 正文实体自动内联链接：名词 / 人物在正文中点击即跳详情页
- 中英对照标注管线（词表 + 幂等 + 污染扫描门禁）
- 科学符号风 SVG 占位图管线，真实素材（腾讯剧版 / TMDB）同名覆写接入
- 内容校验脚本：引用完整性 + 双向链接对称 + self-test 自检
- 单元测试：`node --test`（星空引擎 + 图谱派生/布局共 13 用例）

## 开发

```bash
npm install
npm run dev        # 本地开发（localhost:4321）
npm test           # 单元测试
npm run validate   # 内容校验门禁
npm run build      # 构建 + sitemap
```

部署：GitHub Pages（`SITE_URL` / `BASE_PATH` 环境变量控制域名与子路径）。
