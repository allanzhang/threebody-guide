# 三体世界图鉴

面向没读过《三体》的人：顺着时间线，读懂整个三体故事；也为读过的人提供概念与人物都能查的全景图鉴。全站剧透，以刘慈欣《三体》三部曲为唯一正史。

## 功能一览

- **时间线**：五纪元年表长卷，大事件附「关键转折」解读块
- **全景图谱**（`/graph`）：交互式知识图谱——三卷脉络、人物交会、概念相连。节点/边从内容数据自动派生，骨架层（39 节点）/ 全量层（215 节点）切换，类型筛选。**点击节点锁定高亮**（关联节点联动，拖动/平移不丢状态，点击空白清除），**鼠标停留高亮节点**显示悬浮详情卡（可移入卡片点击直达详情页），滚轮缩放 + 拖拽平移
- **概念册 / 人物墙**：132 条设定卡（法则理论 / 科技器物 / 组织文明 / 天文与宇宙 / 物理与时空），每条「书里怎么讲 + 科学底子」，天文与物理两组为原著科学名词一句话科普；人物四段式来路 + 「他的遗产」
- 解读层全量覆盖：概念「细思极恐」132/132、事件「关键转折」48/48、人物「他的遗产」27/27（概念页 / 时间线 / 人物页渲染，图谱悬浮卡同步）

## 构建技术

- **Astro 5** 纯静态生成；客户端仅渐进增强（星空 Canvas、图谱交互、滚动渐显），零框架零运行时依赖
- 深空视觉体系：近黑底色 + 暗角星云渐变 + 胶片噪点层，苍黄（红岸）× 冷蓝（宇宙）双强调色
- `content/` 五套 JSON 数据源（书 / 纪元 / 事件 / 概念 / 人物）以 id 互相引用、双向对称校验；全站正文统一纯中文口径（去除英文括注与别名，保留 L1–L5、SETI 等必要科学记号）
- 知识图谱数据管线：`buildGraph` 派生节点/边（跨类型同名 id 命名空间隔离）+ 确定性分层坐标布局（纯函数，可测）
- 正文实体自动内联链接：概念 / 人物 → 详情页，事件名 → 时间线锚点（概念/人物优先于同名事件）
- 内容校验脚本：引用完整性 + 双向链接对称 + 孤立检测 + self-test 自检（接入 git pre-commit 门禁）
- 单元测试：`node --test`（星空引擎 + 图谱派生/布局共 15 用例）
- 科学符号风 SVG 占位图管线，真实素材（腾讯剧版 / TMDB）同名覆写接入

## 开发

```bash
npm install
npm run dev        # 本地开发（localhost:4321）
npm test           # 单元测试
npm run validate   # 内容校验门禁
npm run build      # 构建 + sitemap
```

部署：GitHub Pages（`SITE_URL` / `BASE_PATH` 环境变量控制域名与子路径）。
