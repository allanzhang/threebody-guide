# 漫威电影世界图鉴网站 · 设计文档

- **日期**：2026-08-22
- **状态**：设计已确认，待实施
- **产出方式**：Brainstorming 协作设计（决策均与需求方逐条对齐）

## 一、定位

**一句话定位**：面向非漫威迷的 MCU 剧情时序图鉴——顺着读就能看懂整个漫威电影世界。

**目标用户**：非漫威迷观众。核心诉求是"我看了某部电影，想知道这人是谁、之前发生了什么、剧情走向如何"，而不是粉丝向的战力分析、漫画考据、周边资讯。

**产品形态**：纯静态内容站，一本"漫威电影世界图鉴"——以大幅海报、大字号、大留白的排版取胜，像高级杂志/画册，而非交互式应用。

## 二、差异化（对比 manweimi 等现有站）

| 维度 | manweimi 等资讯站 | 本项目 |
|------|-----------------|--------|
| 目标用户 | 漫威粉丝 | 非漫威迷路人 |
| 内容范围 | 电影+漫画+玩具+资讯 | 仅电影世界，砍掉漫画设定与资讯 |
| 时间线 | 纯文字纵向列表，不可点击 | 宽屏可视化排版，条目关联人物详情 |
| 人物 | 百科字段（身高体重等），与电影割裂 | 三段式深度描述（是谁/作用/故事线），与电影互链 |
| 结构 | 板块割裂 | 人物—事件—电影三者打通互跳 |

参考竞情：manweimi 的"电影时间轴"页面已按剧情内部时序排列（公元前1260年瓦坎达 → 未来作品），验证了时序排列方向的正确性；但其呈现为纯文字列表、人物与时间线割裂，恰好留下"结构化理解工具"的空缺。

## 三、关键决策记录

以下决策均在 brainstorming 过程中逐条确认：

1. **内容范围**：以 MCU 正史电影为主。不纳入索尼蜘蛛侠系列、福克斯 X 战警系列全量内容；但当 MCU 剧情中出现跨宇宙/外部版权方人物时（如《英雄无归》三版蜘蛛侠同框、《死侍与金刚狼》），必须给出背景解释和剧情串联，保证主线故事统一可理解。数据结构预留多宇宙归属字段。
2. **信息架构**：时间线为主导航轴（观众顺着看就懂剧情走向）+ 人物墙为第二核心（深度内容承载）+ 电影剧集为辅助关联层。
3. **时间线排序**：按故事内部时序排列（B 方案），不提供上映顺序视图，不展示上映时间。
4. **剧透策略**：不控制剧透，人物角色和电影剧情核心内容全量列出，不折叠。
5. **内容来源**：从公开资料整理——TMDB、豆瓣、时光网，重点参考 manweimi.cn 的时间轴与百科结构。
6. **技术形态**：纯静态网站。不用动态效果，不用 JS 交互，最简洁实现。不做电影视频切片，核心呈现方式为文字 + 电影海报图片的大幅排版。
7. **视觉基调**：宽屏制作（最大宽度 1440px，头图允许全屏宽），追求震撼效果，不小气。震撼感来自大幅面、大字号、大留白的排版本身，而非动效。

## 四、站点地图

```
首页
├── 时间线页（核心页面，按剧情时序纵向长卷）
├── 人物墙页（角色卡片网格 → 点入人物详情页）
└── 人物详情页（性格、作用、成长弧线、关联电影）
```

**YAGNI 清单（明确不做）**：搜索、用户系统、评论、视频切片、动态特效、上映顺序切换、漫画宇宙内容、新闻资讯板块、筛选交互、地图/关系图谱可视化。

## 五、页面设计

### 5.1 时间线页（核心页面）

**整体布局**：纵向长卷式，宽屏（最大 1440px）。中央贯穿细线作为时间轴脊，作品条目挂轴排列。

**时代篇章结构**：

- 全站按叙事纪元分段：远古与二战 → 复仇者集结 → 内战与分裂 → 无限战争 → 多元宇宙时代
- 每个篇章开篇为**全宽（100vw）头图**，高度 60–70vh，电影剧照级大图 + 大标题 + 3–4 行时代导读（帮路人建立大框架）
- 每个篇章一套主题色（二战篇暗军绿、集结篇钢铁红金、无限篇紫、多元宇宙篇青蓝），篇章内的时间轴脊、年份大字、注解框跟随换色，形成"翻章换幕"节奏
- 篇章起始年份用 200px+ 描边大字做背景装饰层，压在内容后形成杂志封面层次感

**时间线条目（常规）**：

1. 剧情年份标记 — 大字号衬线体视觉锚点
2. 电影海报 — 放大至 420–480px 宽，与文字区左右并排（各占约 50%）
3. 作品名 + 副标题（如"美国队长：复仇者先锋 / 二战篇章"）
4. 剧情梗概 — 150–250 字，讲清"发生了什么、和前后剧情的因果"
5. 关联人物行 — 该片主要角色名，可点击跳人物详情页
6. 串联注解框 — 灰底小字块，解释跨宇宙/版权方人物（例：《英雄无归》条目下注明"托比/加菲两代蜘蛛侠来自索尼电影宇宙，与 MCU 是平行世界"）

**时间线条目（大事件特别版）**：复联1、无限战争、终局之战等关键节点升级为全宽特别条目——海报/剧照横铺、超大片名、剧情梗概加倍详细，排版上让"大事件"有"大"的样子。

**实现约束**：纯 CSS（锚点跳转 + sticky 年份侧栏导航），零 JS 动效。

### 5.2 人物墙页

**布局**：宽屏网格，每行 5–6 张竖版角色卡（约 220×320px），铺满 1440px 宽度，间距紧凑，形成群像墙整体气势。

**卡片内容**：角色大幅肖像 + 角色名 + 一句话身份标签（如"托尼·斯塔克 / 钢铁侠 / 复仇者创始人"）。

**视觉焦点**：初代核心六人（钢铁侠、美队、雷神、浩克、黑寡妇、鹰眼）给双倍尺寸大卡，打破网格单调。

**分组方式**（纵向滚动依次呈现，不做筛选交互）：

1. 复仇者核心 — 初代六人 + 二代主要成员
2. Solo 英雄 — 奇异博士、黑豹、蜘蛛侠、惊奇队长、尚气等
3. 银河护卫队 — 独立分组
4. 神域与魔法侧 — 阿斯加德家族、古一、旺达
5. 反派堂 — 灭霸、洛基、奥创、海拉、康（反派单独一堵墙本身即是看点）
6. 重要配角 — 尼克·弗瑞、佩吉·卡特、战争机器等

### 5.3 人物详情页

**结构**：全宽头图（角色剧照 70vh）+ 大字角色名，下方三段式排版：

- **他是谁** — 身份、能力、性格特质（150–200 字，路人视角白话）
- **他的作用** — 在整个 MCU 故事中承担的叙事角色和关键抉择
- **他的故事线** — 按时序列出出场电影及该片中他的剧情走向，每部配小海报，可跳回时间线对应条目

## 六、技术方案

**技术栈**：Astro（纯静态生成，零客户端 JS）+ 手写 CSS。部署 Vercel 或 Cloudflare Pages，零服务器成本。

**图片策略**：海报/剧照/肖像本地存放，构建时压缩为 WebP 多尺寸。

**数据模型**：

```
content/
├── movies.json     # 电影：id、片名、剧情年份、海报、梗概、
│                   #   出场人物id[]、时代篇章id、是否大事件、跨宇宙注解
├── characters.json # 人物：id、姓名、代号、阵营分组、肖像、身份标签、
│                   #   三段式文案（是谁/作用/故事线）、关联电影id[]、宇宙归属
├── eras.json       # 时代篇章：id、名称、主题色、头图、导读文案、年份范围
└── images/         # 海报、剧照、肖像图
```

关联跳转（电影→人物、人物→电影、时间线→详情）全部靠 id 互相引用，构建时自动生成链接——"三者打通"的全部实现，不需要任何动态功能。

## 七、内容生产流程

AI 辅助流水线：

1. **事实底稿**：从 TMDB API 拉结构化字段（片名/年份/演员/海报图）；时序和事件脉络参照 manweimi 时间轴 + 豆瓣剧情简介交叉核对
2. **AI 初稿**：LLM 按统一模板批量生成三段式文案（尤其"他的作用"这类分析性内容）
3. **人工审校**：逐篇核对事实细节，重点盯三类高频错误：
   - 漫画设定混入电影设定
   - 剧情年份错位
   - 跨宇宙人物归属说错
4. **图片**：TMDB 官方海报与剧照（个人非商用项目风险低；若商用需重新评估 TMDB 使用条款）

## 八、分期与节奏

### 内容分期

| 阶段 | 内容范围 | 说明 |
|------|---------|------|
| M1 · 骨架上线 | 无限传奇完整故事（钢铁侠1 → 终局之战） | 三大页面全功能上线；剧情完整闭环，路人最常问的故事 90% 在这段 |
| M2 · 多元宇宙 + 打磨 | Phase 4–6 全量 + 跨宇宙串联注解 + 体检打磨项 | 三版蜘蛛侠同框、死侍与金刚狼等跨宇宙解释重点打磨；并入导航/SEO/视觉等工程改进 |
| M3 · 打磨与收录 | 最新作品持续收录 + 排版精修 | 新片上映后 1–2 周内补录，形成收录习惯 |

> **M2 已并入的工程打磨项**（2026-08-23 全站体检确定）：① 时间线侧栏篇章定位 + 锚点滚动补偿；② SEO（favicon/og/逐页description/canonical/robots/sitemap）；③ 真实 WebP 海报接入替换占位图；④ 移动端真机复测；⑤ Phase 6 未上映作品标注「待收录」。（详见体检记录）

### 开发节奏（vibe coding 团队口径）

1. 第 1 周：Astro 项目搭建 + JSON schema 定稿 + 时间线页样式（宽屏震撼版排版是全站难点，先攻）
2. 第 2 周：人物墙 + 人物详情页 + 三者互链
3. 第 3 周：M1 内容灌入（AI 初稿流水线）+ 人工审校
4. 第 4 周：视觉精修（篇章主题色、头图、大字装饰层）+ 部署上线

### 质量门禁（上线前）

- 事实错误零容忍——路人百科站错一处，信任归零
- 移动端排版必测（静态站手机流量会占大头）
- 图片全部 WebP 压缩
